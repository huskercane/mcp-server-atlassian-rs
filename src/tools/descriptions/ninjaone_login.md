Log in to a configured NinjaOne server and cache a console session key for the other `ninjaone_*` tools. Pass `server` as an alias from `NINJAONE_SERVERS`, or omit it to use `NINJAONE_URL`. The email and password are server-held configuration (`NINJAONE_EMAIL` / `NINJAONE_PASSWORD`) and are never accepted as arguments. When the account has MFA enabled, the current one-time code comes from the server-configured `NINJAONE_TOTP_COMMAND` or `NINJAONE_TOTP_SECRET` if either is set; otherwise pass it as `mfaCode`. The session key is kept in memory for the life of the MCP server process, replayed as the `sessionKey` cookie on later calls, and is never returned in full — call this once per server process, and again if a later call reports the session expired.
