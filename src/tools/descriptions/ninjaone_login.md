Log in to a configured NinjaOne server and cache a console session key for the other `ninjaone_*` tools. Pass `server` as an alias from `NINJAONE_SERVERS`, or omit it to use `NINJAONE_URL`. The email and password are server-held configuration (`NINJAONE_EMAIL` / `NINJAONE_PASSWORD`, or the `email` / `password` fields of the chosen `NINJAONE_SERVERS` entry) and are never accepted as arguments. Each server can therefore log in as a different account, which is what decides the division and role the session sees; the response reports which account and division it got. When the account has MFA enabled, the current one-time code comes from the server-configured `NINJAONE_TOTP_COMMAND` or `NINJAONE_TOTP_SECRET` if either is set; otherwise pass it as `mfaCode`. The session key is kept in memory for the life of the MCP server process, replayed as the `sessionKey` cookie on later calls, and is never returned in full — call this once per server process for each server you use, and again if a later call reports the session expired.
